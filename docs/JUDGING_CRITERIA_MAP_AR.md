# خريطة معايير التحكيم والأدلة — مَظَانّ

هذه الصفحة مدخل سريع للمحكّم. تربط كل معيار معلن بما يمكن تجربته أو مراجعته في المنتج والمستودع، وتفصل بين الدليل القابل للتحقق والادعاءات التي لا تزال تحتاج مراجعة بشرية مستقلة.

## 1. جودة الحل التقني وتوظيف الذكاء الاصطناعي — 25%

### أين يعمل الذكاء الاصطناعي؟

1. يقترح مخططًا منظمًا ومحاور بحث مفسّرة ضمن عقد صارم.
2. تستخدم embeddings لاسترجاع الصلة الدلالية إلى جانب البحث اللفظي.
3. يفحص نموذج الصلة السجل الكامل مقابل الموضوع والمحور، ويميز بين الصلة المباشرة والسياقية.

### أين لا يُسمح له بالقرار؟

- لا يولد آية أو حديثًا من ذاكرته.
- لا يحوّل نتيجة embedding أو مقتطف بحث إلى دليل.
- لا يعتمد الدليل نيابة عن الخطيب.
- إذا فشل المخطط أو خالف العقد، يظهر fallback منهجي محدد بدل مخرج غير مضبوط.

### دليل قابل للقياس

- فهرس القرآن: `6236` آية كاملة.
- فهرس الحديث الدلالي: `3552` سجلًا عربيًا مكتملًا ضمن النطاق الموثق.
- الاختبارات: `103/103` ناجحة.
- اختبار الضغط: `15` موضوعًا و`332` سجلًا كاملًا جرى جلبها وفحصها في التشغيل الموثق.

هذه الأرقام تقيس التنفيذ والنطاق المحددين، ولا تمثل دقة شرعية عامة.

## 2. تحقيق النفع وفق المسار — 20%

ينتمي المشروع إلى مسار **أدوات المعرفة والتحقق لتمكين المعرّفين بالإسلام**. قيمة مَظَانّ ليست زيادة كمية المحتوى، بل تقليل فجوة العمل بين العثور على نص وبين استخدامه بمسؤولية:

- كل دليل يعود إلى مصدره.
- كل دليل يظهر مع سبب صلته والمحور المقترح له.
- يستطيع الخطيب القبول أو الاستبعاد أو تغيير موضع الاستخدام.
- تتحول الاختيارات إلى هيكل كتابة مرتبط بالمراجع بدل قائمة روابط منفصلة.
- تظهر الفجوات صراحة، فلا يوحي النظام باكتمال غير موجود.

## 3. الموثوقية والسلامة العلمية — 15%

ضوابط السلامة جزء من خط التنفيذ وليست تنبيهًا نصيًا فقط:

- الآية والحديث وحدتان كاملتان غير قابلتين للاقتطاع بوصفهما دليلًا.
- يرفض النظام اختلاف معرف المصدر أو موضعه.
- يحجب سجل الحديث الدلالي إذا تغيرت بصمة المتن بين الفهرسة والجلب.
- يبقى شرح الناشر منفصلًا عن النص المصدر.
- تعذر المصدر، أو استخدام cache، أو غياب التغطية حالات ظاهرة للمستخدم.
- تُرفض الفتوى الشخصية قبل استدعاء المخطط أو الاسترجاع.
- الموضوعات الخلافية تحتاج بوابة مراجعة بشرية صريحة.

لم تُستكمل مراجعة شرعية مستقلة تسمح بادعاء دقة عامة؛ يظهر هذا القيد في [النتائج النهائية](../evaluation/FINAL_RESULTS_2026-10-06.md) بدل استبداله بنسبة تسويقية.

## 4. الابتكار والقيمة المضافة — 15%

المقاربة الشائعة تبدأ بسؤال وتنتهي بنص مولد. مَظَانّ تعيد تعريف دور الذكاء الاصطناعي: **اقتراح مسار بحث وترتيب مواد للمراجعة، لا الاستحواذ على قرار الباحث**.

القيمة المضافة في الجمع بين:

- بحث لفظي يحافظ على المطابقة المصدرية.
- بحث دلالي يوسع الاستدعاء دون تحويل المتجهات إلى أدلة.
- جلب كامل وفحص بصمة بعد مرحلة الترشيح.
- تصنيف مباشر/سياقي مرتبط بعلاقة الموضوع، لا بتشابه كلمات فقط.
- سجل قرار بشري يربط الدليل بموضع استخدامه.

## 5. تجربة المستفيد والتواصل والإتاحة — 10%

- رحلة عربية من اليمين إلى اليسار ومصطلحات تشرح وظيفة كل خطوة.
- الأسئلة الاختيارية لا تعيق بدء البحث.
- يمكن تعديل المحاور وإعادة ترتيبها قبل الاسترجاع.
- تفاصيل العزو الثانوية متاحة عند الطلب ولا تزاحم قرار المراجعة.
- التنقل المتتابع يحافظ على المرشحات وحالة القرار.
- الواجهة متجاوبة، وأهداف اللمس لا تقل عن `44px` في نظام التصميم.
- حالات الانتظار والتعذر والفجوة لها لغة واضحة وغير احتفالية.

## 6. واقعية التشغيل والاستكمال — 10%

المشروع ليس نموذج واجهة فقط. النسخة العامة تقدم API وواجهة وحفظًا واسترجاعًا وتصديرًا، وتعمل داخل حاوية قابلة للبناء. ويتحقق CI من:

- تثبيت الاعتمادات من lockfile.
- نجاح الاختبارات.
- إمكان بناء صورة Docker.
- تطابق سجل المصادر المولد مع النسخة الملتزمة.

يعتمد التخطيط الدلالي وبعض فحوص الصلة على مزود نموذج خارجي؛ عند غيابه توجد حالة fallback أو امتناع ظاهرة، ولا يُخفى الاعتماد التشغيلي.

## 7. وضوح العرض وإتاحة التحقق — 5%

### مسار تحقق مقترح في خمس دقائق

1. افتح [التجربة](https://mazann.51.254.141.28.sslip.io/) وأدخل موضوعًا عربيًا محددًا.
2. راجع سبب كل محور وعدّل الخطة أو اعتمدها.
3. افتح سجلًا كاملًا وانتقل إلى مصدره.
4. غيّر موضع استخدام الدليل ثم اقبله أو استبعده.
5. راجع هيكل الكتابة المرتبط بالأدلة والفجوات.

لإعادة التحقق برمجيًا:

```bash
npm ci --ignore-scripts
npm test
npm run manifest:sources
```

## حدود يجب أن يعرفها المحكّم

- لا تقدم النسخة فتوى شخصية ولا خطبة نهائية جاهزة.
- تقييم الملاءمة الشرعية النهائية مسؤولية مراجع مؤهل.
- تغطية الحديث الدلالية تخص سجلات HadeethEnc العربية الموثقة، وليست فهرسًا لكل السنة.
- روابط التفسير الحالية سياقية ومحدودة، وليست فهرس تفسير مستقلًا.
- مساحة المتصفح الحالية ليست نظام حسابات مؤسسيًا ولا تصلح لبيانات سرية.

إظهار هذه الحدود جزء من تصميم الثقة في مَظَانّ، لا نقص مخفي في العرض.
